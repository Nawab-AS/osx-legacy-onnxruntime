# ONNX runtimes
Contains the CPU-only ONNX runtime binaries for v1.16.3. Taken from the official [microsoft/onnxruntime](https://github.com/microsoft/onnxruntime/releases/tag/v1.16.3) repo.


This repo is a centralized place for downloading legacy-compatable onnxruntime libraries for apps that download them on runtime rather then bundling in the binary.
